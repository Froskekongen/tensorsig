# Security policy

Please report suspected vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/Froskekongen/tensorsig/security/advisories/new).
If that form is unavailable, email [erlend.aune@pm.me](mailto:erlend.aune@pm.me).
Do not open a public issue for an unpatched vulnerability.

Security fixes are applied to the latest release. Older release branches are
not maintained.
